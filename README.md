# GEO SURFER AI — المرحلة 1

تطبيق أندرويد (Kotlin + WebView + Leaflet) لعرض خريطة متعددة الطبقات.

## الميزات الحالية
- بحث بالإحداثيات: عشري أو درجات/دقائق/ثواني (N/S/E/W أو شمال/جنوب/شرق/غرب، وأرقام عربية)، نظام WGS84.
- خرائط أساس: قمر صناعي Esri، طبوغرافية، شوارع.
- طبقات: حرارية نهارية/ليلية (MODIS)، طيفية SWIR، أضواء ليلية (VIIRS)، تضاريس ASTER GDEM، جيولوجية (Macrostrat).
- لكل طبقة: شفافية، تباين، سطوع، ووضع دمج (blend) لمقارنة الطبقات ودمجها.
- تحديد الموقع الحالي.

## البناء
- محلياً: افتح المشروع في Android Studio (JDK 17) ثم Build > Build APK.
- GitHub Actions: ارفع المشروع، يعمل `.github/workflows/build.yml` تلقائياً ويرفع ملف APK كـ artifact.
  (لا يحتاج gradle wrapper؛ الـ workflow يثبّت Gradle 8.7.)
